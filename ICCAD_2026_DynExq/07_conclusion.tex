\section{Conclusion}

\systemname\ reframes single-GPU MoE memory management as dynamic fidelity allocation. A fixed number of higher-precision slots follows workload-dependent router traffic, while a complete lower-tier expert set preserves on-device coverage. Immutable versioned handles, leases and CUDA events, fixed-block pools, and admission-before-allocation make replacement safe under an explicit runtime-owned memory envelope. Across FP16/INT4 and INT4/INT2 tier pairs, the evaluation studies the resulting quality--throughput--memory tradeoff against static residency and executable offloading where supported. Future work includes fused handle-aware kernels, persistent host representations, tenant-aware objectives, and coordinated multi-GPU budgets.
