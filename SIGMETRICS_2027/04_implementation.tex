\section{Implementation}
\label{sec:impl}

We implement \systemname\ in Python with PyTorch and HuggingFace
Transformers~\cite{paszke2019pytorch,wolf2020transformers}.
Three mechanisms below are the ones Section~\ref{sec:design} leaves to the
implementation: the inputs of the forecaster, the bytes stored for each
representation tier, and the placement of one extent in the shared arena.

\paragraph{Forecaster.}
For each layer retained by \(S_t\), the forecaster in
Section~\ref{sec:leases} reads pre-gating logits from the snapshot when the
snapshot contains them.
Otherwise it ranks that layer's experts by recent activation counts and
returns a prefix of configured width.
Low confidence lengthens this prefix and leaves \(S_t\) unchanged.
When the forecast is late for the layer that is about to run, the generator
uses recent routing history and the forward path continues.
The admission rule reads the forecast from the steps above.

\paragraph{Envelope and representations.}
At startup \(S_t\) is the number of layer intervals required to copy one layer of
absent-expert bytes at the copy rate \(C\), clipped to the configured bounds.
Section~\ref{sec:coordinator} then updates that depth from observed stall and
pollution.
Before a timed run, both tiers of each layer are packed into pinned host
memory, and that layer's source weights are released once both packs exist.
The checkpoint fixes the tier pair, so the two representations stay the same
as \(B\) changes.
While a layer runs, each tier that the layer contains is issued as one
grouped GEMM.

\paragraph{Shared arena.}
Each device-resident expert representation occupies one extent, a contiguous
byte range that holds that representation.
Layer, tier, and lease purpose share this arena.
The arena is backed by one or more preallocated segments, each a contiguous
buffer, and every extent is taken from a single segment.
The allocator rounds a request up to a multiple of 256 bytes and selects the
smallest free range, among all segments, that can hold the rounded size.
When a range is returned, adjacent free ranges in the same segment are merged.
