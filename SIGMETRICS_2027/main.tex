\title{The Optimal Expert Prefetch Horizon Is Set by Precision}

\begin{abstract}
The optimal prefetch horizon for expert weights is set by precision: \(\PhiRatio=B/P_{\mathrm{lo}}\), the device budget divided by a low-precision copy of every expert, decides whether those bytes buy residency or lookahead.
Precision assignment assumes that low-precision copy always fits, while prefetching assumes expert size is fixed and a longer horizon always helps; the two assumptions exchange places at \(\PhiRatio=1\).
When \(\PhiRatio\ge 1\) the minimizing horizon is zero and leftover bytes raise the precision of experts the router uses; when \(\PhiRatio<1\) it is the smallest lookahead that hides the predicted misses inside the overlap window and the budget, and prefill versus decode crosses that boundary inside one request.
\systemname\ computes this horizon from measured expert sizes, tracks it by at most one layer per period, and changes precision only while the byte budget and the latency band both hold.
A sweep of budgets, models, and devices tests the predictions against precision-only residency, horizon-only prefetch, and a composition that lets each policy spend the full budget.
\end{abstract}
